# ADR-016: Licensing: AGPL-3.0

- **Status:** Accepted
- **Date:** 2026-11-13

## Context

Open decision §20.14. The project should be open source while discouraging closed hosted forks.

## Decision

The community/self-hosted edition is licensed under GNU AGPL-3.0.

## Consequences

- Anyone offering a modified version over a network must publish their changes.
- A commercial license or paid SaaS can be layered later by the copyright holder.
