# ByteContent brand (starter)

A starter identity for **ByteContent by ByteRings**. Replace these files when
the final logo and colours are ready; everything else reads from the tokens
below.

## Logo

| File | Use |
| ---- | --- |
| `mark.svg` | App icon, favicon, avatar (square, works from 16 px) |
| `logo.svg` | Mark + wordmark on light backgrounds |
| `logo-dark.svg` | Mark + wordmark on dark backgrounds |

The mark is a "B" built from content blocks: a spine and two stacked
blocks, on a violet-to-teal gradient. Keep clear space of at least a quarter
of the mark's width around it. Do not stretch, recolour or add effects.

## Type

System UI stack (`Inter`, `Segoe UI`, `system-ui`, sans-serif) for UI and
wordmark; `ui-monospace` stack for code. Headings use tight letter spacing
(-0.02em).

## Name

Write **ByteContent** (one word, capital B and C). The company is
**ByteRings**. Use "ByteContent by ByteRings" where the company should be
visible. The CLI and npm package are lower case: `bytecontent`.
